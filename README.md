# AI Resume Analyzer

AI-powered Resume Analyzer built using Spring Boot, Next.js, JWT Authentication, PostgreSQL, and Google Gemini AI.

## Features

- User Registration & Login (JWT Authentication)
- Resume Upload (PDF/DOCX)
- Resume Parsing & Text Extraction
- AI Resume Analysis using Gemini AI
- Resume Score Generation
- Skills Extraction
- Experience & Education Analysis
- Strengths and Weaknesses Detection
- AI Improvement Suggestions
- Resume History Tracking
- Job Description Matching
- Dashboard Analytics

## Tech Stack

### Backend
- Java 21
- Spring Boot
- Spring Security
- JWT Authentication
- Spring Data JPA
- PostgreSQL
- Maven

### Frontend
- Next.js
- React.js
- TypeScript
- Tailwind CSS

### AI Integration
- Google Gemini API
